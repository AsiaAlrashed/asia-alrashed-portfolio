A regression workflow for construction planning that ends in a usable interface, not a notebook.

01 — Problem

Planning needs three answers at once

Construction planning requires estimating when material orders will arrive while simultaneously coordinating activity costs and required material quantities. Those three questions are usually answered in separate places, by hand, and a change to one silently invalidates the others.

Objective. Develop a data-driven prediction and planning workflow that combines regression modeling with construction cost and material calculations.

02 — Workflow

From raw project data to a planning decision

Construction data↓ Data analysis↓ Data preprocessing↓ Regression models↓ Model evaluation↓ Order arrival prediction↓ Activity cost estimation + material quantity calculation↓ Interactive user interface

Cost estimation and material quantity calculation run off the same predicted arrival, which is what keeps the three answers consistent with each other.

03 — Engineering components

What the workflow is made of

Data analysis & preprocessing

Understanding the project data and preparing it, which is where most of the real work in a regression problem lives.

Regression model development

Models built to predict order arrival time, then evaluated rather than assumed.

Model evaluation

Held-out evaluation to establish that the predictions are usable for planning.

Activity cost estimation

Predicted arrival feeds cost estimation for the affected activities.

Material quantity calculation

Required quantities computed alongside cost, from the same inputs.

Interactive application

A user interface so planners can run scenarios themselves, which is what turns a model into decision support.

04 — Result

Low prediction error, delivered as a planning tool

The final regression workflow achieved low prediction error on evaluation. The engineering result is that arrival time, activity cost, and material quantity are produced together from one model run, inside an interface a planner can actually use.

Scope of this write-up

No MAE, RMSE, MAPE, R², or accuracy figure is published for this workflow, so none is stated. "Low prediction error" is a qualitative summary of the evaluation.
