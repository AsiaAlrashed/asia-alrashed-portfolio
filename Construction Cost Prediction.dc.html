Main comparison prioritizes R² and MAE because both are available across all supplied model results. XGBoost RMSE is not visually compared against MSE values from other models.

Linear Regression — 0.969
Lowest MAE
XGBoost — 0.756

Linear Regression achieved the highest R² score, indicating the strongest explained variance among the evaluated models. XGBoost achieved the lowest MAE, demonstrating strong average prediction error in the target variable’s original units. Random Forest remained competitive, while Decision Tree showed the weakest generalization with larger prediction deviations visible in several samples.
