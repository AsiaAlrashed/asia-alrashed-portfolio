Medical Imaging AI System

Deep learning across two very different kinds of medical image: flat X-rays and 3D CBCT volumes.

I trained and evaluated deep learning models for medical image analysis and classification, working with 2D X-ray images and 3D CBCT scans. The work covered the full computer vision cycle: preparing and augmenting imaging data, building classification and segmentation models, then evaluating and tuning them.

( 01 ) The problem

Two modalities that do not behave the same way

X-ray and CBCT are not interchangeable inputs. An X-ray is a single projection; a CBCT scan is a volume, which changes how data is loaded, augmented, and fed to a network, and it changes what the model can learn. Medical imaging data is also limited and sensitive, so preparation matters as much as architecture.

2D versus 3D

A flat projection and a reconstructed volume need different input handling and different model treatment.

Limited data

Medical imaging datasets are small compared to general vision datasets, which makes preparation and augmentation decisive.

Two tasks

Classification answers what is present; segmentation answers where it is. Both were part of the work.

( 02 ) Data preparation

Preparation before architecture

Before any training, imaging data was prepared and augmented so the models saw consistent, usable inputs across both modalities.
