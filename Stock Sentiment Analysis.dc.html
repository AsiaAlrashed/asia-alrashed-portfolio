01 — Problem

Too much news to read consistently

Large volumes of financial news make it difficult to evaluate market sentiment consistently across multiple stocks. Manual reading does not scale, and it is not repeatable: the same article read twice can be scored differently.

Objective. Create an NLP pipeline that automatically transforms financial news into structured sentiment signals and stock-ranking information.

02 — Pipeline

From headline to ranked stock

Financial news↓ Data processing↓ DistilBERT↓ Sentiment classification
Positive Neutral Negative
↓ Weighted sentiment scoring↓ Stock ranking↓ FastAPI↓ Downstream applications
03 — Model & aggregation

The ranking is the point, not the classification

Transformer classification

Financial sentiment classified with DistilBERT, chosen as a compact transformer that can process news volume without a heavyweight serving footprint.

Weighted aggregation

Individual headline labels are aggregated into weighted sentiment scores per stock. Stopping at per-article classification would leave the user with the same volume problem they started with.

Serving

The workflow runs as an end-to-end pipeline with automated processing and FastAPI-based serving, so ranking output is consumable by downstream applications rather than living in a notebook.

04 — Result

89% classification performance

The sentiment classifier reached 89% on its evaluation. That figure is reported as classification performance rather than accuracy or F1, because the exact metric is not currently confirmed.

Scope of this write-up

89% is stated without a metric name because the exact evaluation metric is not currently confirmed. No dataset size, market coverage, or trading result is claimed.
