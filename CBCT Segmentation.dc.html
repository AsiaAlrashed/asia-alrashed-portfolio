Neural Canal Segmentation from 3D CBCT

A volumetric segmentation pipeline for dental CBCT, from raw DICOM through manual annotation to inference on new scans.

Model performance

01 — Problem

Segmentation in a volume, not in a picture

Accurate localization and segmentation of neural canals in dental CBCT volumes is an important medical imaging task, and it requires analysis of volumetric 3D image data rather than individual slices. The canal is a thin, continuous structure that only makes sense across depth.

Objective. Build a deep learning workflow capable of learning neural-canal segmentation directly from CBCT volumes.

02 — Data preparation

Getting from scanner output to trainable volumes

DICOM processing

CBCT DICOM series collected and processed into a consistent form before anything is trained on them.

3D volume construction

Slices assembled into volumes, so the model sees the canal as the continuous structure it is.

Manual annotation, 3D Slicer

Ground truth segmented by hand in 3D Slicer, then split into training and validation sets. This is the slowest step and it determines the ceiling on everything after it.

03 — Pipeline

From scan to segmentation to inference

CBCT DICOM↓ DICOM processing↓ 3D volume construction↓ Manual annotation, 3D Slicer↓ Training / validation preparation↓ 3D U-Net / nnU-Net↓ Model training & hyperparameter tuning↓ Neural canal segmentation↓ Prediction / inference pipeline

The final stage matters as much as the model: an inference pipeline means a new CBCT volume can be segmented without repeating the manual work.

04 — Model development

Architecture and tuning

3D U-Net / nnU-Net

A segmentation architecture designed for volumetric medical data, where context above and below a slice is part of the input rather than discarded.

Hyperparameter optimization

Model hyperparameters tuned against the validation split, with evaluation on held-out volumes.

Inference on new volumes

A prediction pipeline that takes an unseen CBCT volume and returns the segmented neural canal.

05 — Result

Approximately 92% model performance

The trained model reached roughly 92% on its evaluation. The specific metric behind that figure is not currently confirmed, so it is presented as model performance rather than labelled as Dice, IoU, or accuracy.

Scope of this write-up

The ~92% figure is reported without a metric name because the exact evaluation metric is not currently confirmed. No dataset size or clinical validation is claimed.
