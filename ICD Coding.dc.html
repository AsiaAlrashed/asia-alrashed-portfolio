Hierarchical Automated ICD Coding

01 — Problem

Thousands of clinically meaningful codes appear only a few times

Automated ICD coding is an extreme multi-label classification problem: a single clinical discharge note can correspond to many diagnosis codes. The difficulty is the long-tail distribution of ICD labels. Frequent codes have substantial training data, while thousands of clinically meaningful codes occur only a few times.

Objective. Develop a hierarchy-aware clinical NLP architecture that improves representation and prediction of rare ICD codes, rather than optimizing only aggregate performance.

02 — Data

MIMIC-III discharge notes and ICD-9 codes

MIMIC-III clinical discharge notes paired with their ICD-9 diagnosis codes. The label space itself carries structure: ICD codes sit in a hierarchy where related diagnoses are neighbours, and that structure is the signal the architecture is designed to exploit.

04 — Engineering detail

The hierarchy is propagated twice, on purpose

HGCN-1, before attention

Operates on the BioClinicalBERT label embeddings to create hierarchy-aware label queries, so a rare code arrives at attention already informed by its neighbours in the ICD tree.

HGCN-2, after attention

Refines the text-conditioned representations using relationships among related ICD codes, so evidence found for one code can support its structural siblings.

Imbalance-aware training

Rare-code-aware training and frequency-sensitive evaluation, because a model tuned on aggregate metrics will quietly abandon the tail.

05 — Evaluation

The ablation is the argument

97.4% Micro-AUC across the label space. The more meaningful result is the tail: Tail-F1 rose from 0.0134 with CAML-only to 0.0344 with the full architecture, roughly a 157% improvement, and each hierarchy pass contributes.
